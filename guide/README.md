# Guide

Detailed documentation for the SCRAPE website archiver. Start with the main [README](../README.md) to set up and capture a site; come here when you want to know more.

| Page | Read it to |
|---|---|
| [sites-yaml.md](sites-yaml.md) | Look up every setting in `sites.yaml`, with examples and what each error message means |
| [runs.md](runs.md) | Understand when captures run, how long they take, the time and size limits, parts, permissions and cost |
| [dashboard-and-page-list.md](dashboard-and-page-list.md) | Understand every field on the dashboard and page lists, how they're built, and how to change their look |
| [code.md](code.md) | Find your way around the code: what each file does and the data passed between them |
| [troubleshooting.md](troubleshooting.md) | Fix something that isn't working |

This folder is called `guide/` rather than `docs/` because `docs/` holds the web dashboard that GitHub Pages publishes.
